    In-Place Document Preservation Engine

    The 10 Critical Rules Enforced On Every Upload

    Strict Non-Destructive In-Place Architecture: Unlike standard spinners that convert documents into markdown and re-render a broken facsimile, Veritas operates directly on native file streams. Only narrative body copy is rewritten to bypass AI detection; all styling, images, and structural elements are immutable.
    RULE 1
    Edit In-Place (Never Recreate From Scratch)

    Modifications happen in-place within the document's original binary stream. For PDFs, PyMuPDF updates stream objects; for PowerPoint, python-pptx edits text-frame shapes; for Word, python-docx rewrites text runs. Documents are never re-created from scratch.

    RULE 2
    100% Non-Text Elements Preserved

    Preserves every non-text element: images, logos, vector shapes, charts, graphs, icons, tables, borders, cells, headers, footers, page numbers, footnotes, hyperlinks, and text boxes remain untouched at original coordinates.

    RULE 3
    Exact Typography & Font Size (Pt) Run-Level Matching

    Maintains typography run-by-run: font family, font size in points (Pt), font weight (bold/semi-bold), italic, underline, text color, highlight, alignment, indentation, line spacing, paragraph margins, and section breaks.

    RULE 4
    Side Headings, Captions & Structural Labels Untouched

    Strict structural filtering locks side headings, headings, subheadings, captions (e.g. Figure 1:, Table 2:, Source:), and table header rows. They are never modified or rephrased.

    RULE 5
    Main Body Copy Only Rewriting

    Only rewrites main narrative body paragraphs and bullet copy to natural, humanized phrasing scoring < 10% AI. Bullet markers (•, -, 1.) and bold lead-in keys are preserved seamlessly.

    RULE 6
    Paragraph Architecture & Balanced Length Parity

    Maintains exact original paragraph order, total paragraph count, and roughly similar length (±10%) so text boxes and slide layouts never break boundaries or wrap awkwardly.

    RULE 7
    Zero Content Removals or Deletions

    Never removes or deletes any section, image, graphic, table, bullet point, slide, or page. Complete 100% document parity is enforced.

    RULE 8
    Native Document Format Retained

    PDF stays native PDF, PPTX stays native presentation slides, and DOCX stays native Word document. No forced conversions or format degradation.

    RULE 9
    Vector PDF Stream Replacement (Zero Rasterization)

    Edits text in existing PDF content streams using precise vector bounding box coordinates and font metrics. Never rasterizes or flattens pages into pixel images.

    RULE 10
    100% Watermark-Free & Zero Branding

    Never adds watermarks, logos, sponsor text, cover pages, or promotional annotations. Exported documents are 100% clean, professional, and unbranded.
